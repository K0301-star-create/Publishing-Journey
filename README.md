# Publishing-Journey

Author · Reviewer · Editor Prototype (Taylor & Francis)

**Live:** https://k0301-star-create.github.io/Publishing-Journey/

Self-contained clickable prototype: one HTML file (inline CSS + vanilla JS, hash routing, state in `sessionStorage`).
Only external dependency: Google Fonts (Aleo, Open Sans).

## Files
- `Author · Reviewer · Editor Prototype · Taylor & Francis.html` — the full prototype
- `index.html` — redirects to the prototype (what GitHub Pages serves at the root)
- `serve.sh` — run it locally

## Run locally
    ./serve.sh          # then open http://localhost:8000

## Use
- **Prototype ▾** (bottom corner) switches role (editor/reviewer/author) and editor workload, and jumps to any step of the author, reviewer and editor journeys or the journey maps.
- Press **H** to hide the prototype controls; "Start again" resets all state.
